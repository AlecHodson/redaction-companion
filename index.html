Redaction Companion

Permanently redact names, terms and phrases from PDFs, Word documents and images before releasing them under a Data Subject Access Request.

1. Terms to redact

Add every word or phrase that must be removed. Each one will be searched for across every loaded file.

2. Files to redact

Accepted types: PDF, DOCX, JPG, PNG. Multiple files are processed one at a time.

or drag files here is not required — click to browse
Privacy: All documents are processed entirely inside your browser using local JavaScript. Files are never uploaded or transmitted to any server — not even to Complete Childcare's own systems — other than the one-off loading of the library code listed below from public CDNs and the Microsoft sign-in used to verify you are an authorised user.
Libraries used (code only, no document data sent): pdf.js, jsPDF, mammoth.js, html2canvas, tesseract.js, MSAL.js.
Image redaction caveat: redaction of photos/scans relies on OCR (optical character recognition) to find the text. OCR can miss handwriting, stylised fonts or poor-quality scans. Always visually check the redacted image before relying on it or releasing it.
